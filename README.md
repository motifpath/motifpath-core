# motifpath-core

Core domain logic and shared libraries for the Motifpath platform.

## Getting started

```bash
npm install
npm test
```

## Structure

```
src/        Source code
  domain/   Domain models and business logic
  services/ Application services
  utils/    Shared utilities
tests/      Test suites
```

## Development

- `npm run build` — compile
- `npm test` — run tests
- `npm run lint` — lint
